data

Set the location of the CheckM reference data.

The data setRoot action stores the location of the CheckM reference data in CheckM’s DATA_CONFIG file. A different DATA_CONFIG file can be given as an optional second argument. Setting the CHECKM_DATA_PATH environment variable is an alternative to this command and takes precedence over it. See Reference data for details.

Arguments

usage: checkm data [-h] action [action ...]

Set path to the CheckM database files.

positional arguments:
  action
                setRoot <DB_PATH> -> set the CheckM data directory to <DB_PATH> (requires permissions)
                or
                setRoot <DB_PATH> <CONFIG_PATH> -> set the CheckM data directory to <DB_PATH> and the CheckM DATA_CONFIG file to CONFIG_PATH (requires permissions)

options:
  -h, --help  show this help message and exit

Example: checkm data setRoot

Example

checkm data setRoot /path/to/my_checkm_data
