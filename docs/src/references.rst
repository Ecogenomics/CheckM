.. _references:

Citing CheckM
=============

If you use CheckM in your research, please cite:

* Parks DH, Imelfort M, Skennerton CT, Hugenholtz P, Tyson GW. 2015.
  `CheckM: assessing the quality of microbial genomes recovered from isolates, single cells, and metagenomes
  <https://genome.cshlp.org/content/25/7/1043.short>`_. Genome Research, 25: 1043–1055.

CheckM relies on several other software packages; we recommend also citing:

* `pplacer <https://matsen.fhcrc.org/pplacer/>`_: Matsen FA, Kodner RB, Armbrust EV. 2010. pplacer: linear
  time maximum-likelihood and Bayesian phylogenetic placement of sequences onto a fixed reference tree.
  BMC Bioinformatics 11: doi:10.1186/1471-2105-11-538.
* `Prodigal <https://github.com/hyattpd/Prodigal>`_: Hyatt D, Locascio PF, Hauser LJ, Uberbacher EC. 2012.
  Gene and translation initiation site prediction in metagenomic sequences. Bioinformatics 28: 2223–2230.
* `HMMER <http://hmmer.org/>`_: `<http://hmmer.org/>`_
