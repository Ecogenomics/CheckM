Outputs

The genome quality estimates and statistics reported by CheckM are produced by the qa command, which is also run as the final step of the lineage_wf and taxonomy_wf workflows. The workflows write the results to quality_report.tsv in the output folder. The files in the output folder are described in Output files.

  • Output files
  • Reported statistics
  • qa output formats

Each command that writes to an output directory also writes a log file, checkm.log, to this directory.
